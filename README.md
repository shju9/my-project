# 나를 알아가는 이야기

배우고 시도하며 만들어 가는 과정을 소개하는 한국어 자기소개·포트폴리오 웹사이트입니다.

## 나에 대한 소개

이 사이트는 제가 어떤 사람인지 직접 소개할 수 있도록 만든 공간입니다. 현재 자기소개 화면에는 별명, 관심사와 취미, 잘하는 것과 배우고 싶은 것, 해 본 활동이나 작품, 앞으로의 목표를 적을 자리가 마련되어 있습니다.

아직 제 실제 소개 내용을 채우지 않아 `[별명]`과 작성 안내가 표시됩니다. 화면에 적힌 그림·운동·음악 등의 예시는 내용을 고를 때 참고할 예시이지, 제 관심사나 경험을 뜻하지 않습니다. 이 README에도 확인되지 않은 개인 정보는 적지 않았습니다.

## 만든 이유

친구나 선생님에게 제가 좋아하는 것과 해 본 일, 앞으로 해 보고 싶은 일을 한곳에서 보여 주고 싶어 만들었습니다. 실명이나 연락처 같은 개인 정보를 공개하지 않고도 제 이야기를 소개할 수 있도록, 별명을 쓰고 미정인 내용은 나중에 채울 수 있게 했습니다.

## 주요 화면과 기능

- **홈:** 사이트의 소개 문구와 자기소개·포트폴리오로 이동하는 링크를 보여 줍니다. 방문자는 이 사이트의 주제와 내용을 빠르게 살펴볼 수 있습니다.
- **자기소개:** 관심사와 취미, 잘하는 것과 배우고 싶은 것, 활동이나 작품, 목표를 순서대로 소개할 수 있는 화면입니다. 아직 실제 내용은 입력되지 않았으며, 사진이나 작품도 준비되면 추가할 수 있습니다.
- **포트폴리오 목록:** 웹사이트, 아이디어, 자유 프로젝트를 주제로 한 카드 세 개를 볼 수 있습니다. 현재 카드는 모두 실습용 예시이며, 실제로 만든 작품은 아닙니다.
- **프로젝트 상세:** 각 예시 카드에서 프로젝트 소개, 목적, 진행 순서, 배울 점을 확인할 수 있습니다. 이 내용 역시 예시이므로 실제 작업으로 바꾸어야 합니다.
- **화면 이동과 접근성:** 상단 메뉴와 링크, 브라우저의 뒤로 가기·새로고침으로 화면을 이동할 수 있습니다. 본문 바로가기 링크와 키보드 포커스도 제공하며, 화면 폭에 따라 콘텐츠 배치를 조정합니다.

## 제작 과정과 배운 점

GitHub Copilot과 대화하며 페이지의 내용과 구성을 정리하고 구현했습니다. 저는 화면을 한국어로 만들고 휴대전화와 컴퓨터에서 보기 편하게 하며, 별명을 사용할 수 있고 개인정보나 확인되지 않은 내용을 넣지 않도록 요청했습니다. 실제 사진이나 작품이 아직 없어도 페이지를 구성하고 나중에 추가할 수 있게 한 것도 제가 정한 방향입니다. 홈의 한 줄 문구도 “나를 알아가는 이야기를, 여기에 담아요.”로 바꾸도록 선택했습니다.

제가 직접 겪은 어려움과 해결 과정, 프로젝트를 만들며 새롭게 배운 점은 아직 구체적으로 정리하지 않았습니다. 확인되지 않은 경험을 사실처럼 쓰지 않고, 실제 작업을 돌아본 뒤 제 말로 보태려고 합니다.

## 사용한 기술

- React 19
- JavaScript (ES modules)
- Vite
- CSS
- Oxlint

## 실행 방법

1. [Node.js 24 LTS](https://nodejs.org/)를 설치합니다.
2. 프로젝트 폴더를 연 뒤 터미널에서 의존성을 설치합니다.

```sh
npm install
```

3. 개발 서버를 실행합니다.

```sh
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 열면 사이트를 볼 수 있습니다. 서버를 종료하려면 터미널에서 `Ctrl + C`를 누릅니다.

코드 검사와 배포용 빌드는 다음 명령으로 확인할 수 있습니다.

```sh
npm run lint
npm run build
```

배포용 파일은 `dist` 폴더에 생성됩니다.

## GitHub Pages에 배포하기

`main` 브랜치에 변경 사항을 푸시하면 GitHub Actions가 코드 검사와 빌드를 실행하고 GitHub Pages에 자동 배포합니다. GitHub 저장소의 **Settings → Pages**에서 배포 소스가 **GitHub Actions**로 설정되어 있는지 확인하세요. 배포가 완료되면 다음 주소에서 사이트를 볼 수 있습니다.

## 앞으로 개선하고 싶은 점

**현재 구현된 것:** 홈, 자기소개 안내 화면, 실습용 포트폴리오 목록과 상세 화면, 반응형 스타일과 화면 이동 기능이 있습니다.

**앞으로 채울 내용:** 공개해도 괜찮은 별명과 실제 관심사·강점·배우고 싶은 것·활동·목표를 직접 정리하고, 실습용 프로젝트 예시를 제가 실제로 만든 작업으로 바꾸려고 합니다. 사진이나 작품은 준비되었을 때 추가하고, 실제 제작 과정에서 겪은 어려움과 배운 점도 확인한 뒤 기록할 계획입니다.
